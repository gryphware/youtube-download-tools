How to use it:
1. git clone this repo
2. download python3 compiler if your machine is doesnt have it (google and some AI can helps you with that)
3. keep your machine safe by create venv in python3 by "python3 -m venv <NAME_YOUR_VENV_HERE>"
4. download Textual by using "pip install textual" (without that you cant execute any single line)
5. final. run "python3 app.py"
